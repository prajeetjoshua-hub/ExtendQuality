# EXtendQuality

EXtendQuality is an explainable, multi-level AI inspection concept for bearing manufacturing MSMEs. It combines OpenCV preprocessing, YOLO defect localisation, a confidence-aware Quality Intelligence Engine, and selective Vision Language Model reasoning.

## Live demo

[Open the EXtendQuality dashboard](https://prajeetjoshua-hub.github.io/ExtendQuality/)

The presentation build is deployed directly from this repository through the
`Deploy EXtendQuality to GitHub Pages` workflow.

## Prototype interface

The current responsive landing page presents three intentionally locked modules:

- Camera Feed — powered by OpenCV and YOLO
- VLM Analysis
- VLM Recommendation

The disabled **Previous Defects** area represents the future inspection-history and analytics workspace.
